需求分析与独立审核 · 这个演示验证什么

输入 → 节点 A（Pydantic AI）→ 节点 B（OpenAI Agents SDK）→ Harness 最终结果。 Hatchet 负责两个节点的调度；Harness 保存业务 Run、每步输入输出、技术关联和最终状态。真实模型模式下，节点 A 生成结构化需求（功能、业务规则、验收标准），节点 B 对其进行独立审核（结论 PASS / NEEDS_WORK、发现的问题、风险和改进建议），最终生成一份需求分析与审核报告。

提交输入→节点 A · 需求分析→节点 B · 独立审核→Run 结果

重要：默认模式只验证跨 SDK 调度、输出持久化和接力合同，不会根据输入生成真实需求报告；配置 Live 后才会执行真实需求分析和独立审核。Cube、审批与非幂等 Tool 是独立能力。
